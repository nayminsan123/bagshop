# Pont Pont Hand-Bag Shop

A modern e-commerce platform for premium handbags, backpacks, and travel bags.

## 🛍️ Features

- **Frontend (Vue.js 3 + Vite)**
  - Modern responsive UI with Tailwind CSS
  - Product catalog with categories
  - Shopping cart with checkout
  - User authentication
  - TikTok video integration

- **Backend API (Node.js + Express)**
  - RESTful API
  - SQLite database
  - JWT authentication
  - Admin dashboard

## 📁 Project Structure

```
bagshop/          # Frontend (Vue.js)
bagshop-api/      # Backend API (Express.js)
```

## 🚀 Quick Start

### Prerequisites
- Node.js v18+ 
- npm or yarn

### Frontend Setup
```bash
cd bagshop
npm install
npm run dev
```

### Backend Setup
```bash
cd bagshop-api
npm install
npm start
```
